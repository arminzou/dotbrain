# docs/

Derived documents, runbooks, and reference material.

This directory is optional — create it when the first doc exists. Content here supplies
evidence and explanations, not authority to adopt requirements. Resolve conflicts against
applicable adopted guidance, including amendments. A document's location alone does not
make a claim current or binding; surface discrepancies between observed behavior and
intended constraints.

Examples: runbooks, adopter guides, design reviews, procedural references.
