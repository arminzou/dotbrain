# docs/

Maintained findings, references, and explanations: runbooks, adopter guides, design reviews,
procedural references.

This directory is optional — create it when the first doc exists. Give each record a stable name
and update it in place; a name with a date or run identifier belongs to run output in `scratch/`.
Content here supplies evidence and explanations, not authority to adopt requirements. Resolve
conflicts against applicable adopted guidance, including amendments. A document's location alone
does not make a claim current or binding; surface discrepancies between observed behavior and
intended constraints.
