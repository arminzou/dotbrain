# 浏览 Brain

项目的私有知识，用网站来看往往比在编辑器里读原始 Markdown 方便。Brain 站点提供排好版的页面、搜索、导航和
渲染好的图表，而内容始终留在项目的私有 Brain 里。

可以用它和 Agent 一起学习项目主题、阅读个人的操作手册、回顾决策、查阅敏感的项目上下文。站点在本地的
`127.0.0.1` 上运行；Dotbrain 不会发布它。

## 和 Agent 一起学习项目主题 {#learn-project-topics-with-an-agent}

用 `teach-me` 和 Agent 一起学习你感兴趣的那部分项目。对话时把 Brain 站点开在旁边：Agent 负责讲解、提问、
带你练习，站点给你一个直观的地方读课程、看图表、查参考。

站点有一个专门的 **Learn** 区域。它的侧边栏按学习 mission 里的主题对课程和参考分组。默认首页会显示
Learn 概览，包括主题卡片和最近的课程；有课程时还会显示一个开始学习的链接。

比如，选一个主题和 Agent 讨论，在浏览器里打开对应的课程，让 Agent 带你过一遍。看图，做回忆练习，
再和 Agent 讨论你的答案。Agent 会记录你展示出的理解，并更新你的学习路径。学习记录也会渲染成页面，
你可以看到哪些已经掌握、哪些还需要练习；它们通过链接和搜索访问，不在主题的课程列表里。

[学习工作流程](learning.md)解释了主题、学习路径、学习记录和暂存的概念如何让学习跨会话延续。
Brain 站点则让这些内容在学习过程中更方便查看和使用。

## 阅读私有的操作手册和项目文档 {#read-private-runbooks-and-project-docs}

把操作说明和内部参考资料放在 Brain 里，这样它们可以包含项目上下文，又不会变成公开的仓库文档。
站点会渲染标题、表格、代码块、链接和 Mermaid 图表，读起来更舒服。

比如，一份私有的部署手册可以链接到恢复流程，以及解释某个约束的设计。按手册操作时顺着这些链接点过去即可，
不用在编辑器里逐个打开 Markdown 源文件来读。

## 在整个 Brain 里搜索 {#search-across-the-brain}

站点会渲染整个 Brain 里的 Markdown，包括私有文档、决策、设计和学习材料。当你记得某个术语或问题，
但不记得文件名时，搜索能帮你找到相关页面。

侧边栏为常用页面提供一条更短的路径。它只管导航，不决定有哪些页面：没放进侧边栏的页面仍然可以通过
链接和搜索访问。有些文件会被跳过，包括符号链接和文件名带方括号的文件；映射规则见
[配置指南](brain-site-configuration.md#how-pages-map-to-urls)。

## 浏览决策和设计 {#navigate-decisions-and-designs}

相对链接把文档和它们在 Brain 中原有路径下的决策、设计连起来。决策状态和设计生命周期的标记，
能帮你分辨哪些记录是当前有效的，哪些描述的是更早的某个时间点。

## 配置阅读体验 {#set-up-the-reading-experience}

按 [Brain 站点配置](brain-site-configuration.md)创建站点、在本地运行、安排侧边栏并调整外观。
也可以让 Agent 的 `brain-site` 技能帮忙维护。

Markdown 仍然是源文件。继续用你习惯的工具编辑，在浏览器里看渲染后的页面。
