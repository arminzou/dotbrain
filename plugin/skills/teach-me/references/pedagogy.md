# Pedagogy

How to teach within the `teach-me` workflow: what to teach next, how to explain it, and how to make it stick.

## Knowledge, skills, wisdom

To learn at a deep level, the user needs:

- **Knowledge**, from high-quality, high-trust resources.
- **Skills**, built through practice with feedback.
- **Wisdom**, from interacting with practitioners outside the learning environment.

Draw knowledge from sources tracked in `RESOURCES.md` and cite them; when it is thin, find trusted sources before teaching. Treat parametric knowledge as a lead to verify, not a source.

Teach only the knowledge the skill requires, first, then practice the skill. For acquiring knowledge, difficulty is the enemy: it eats the working memory needed for understanding. For acquiring skills, difficulty is the tool: effortful retrieval builds lasting memory.

## Zone of proximal development

Each session challenges the user just enough. When they have not named what to learn, read their learning records for the topic, relate them to the topic's section of the mission, and teach the most relevant thing within reach.

## Storage strength

In-the-moment fluency can feel like mastery; long-term retention (storage strength) is the goal. Build it through:

- **Retrieval practice:** recall from memory before seeing the answer.
- **Spacing:** return to earlier material across sessions.
- **Interleaving:** mix related skills in practice.

## Practice formats

Every exercise gives feedback as immediately as possible.

- **Retrieval questions** are reveal-style: the user commits to an answer, then opens it.
- **Skill drills** check the answer automatically. Keep every answer the same length and format so the form gives no clues.
- **Guided real-world steps** walk the user through actions in the real system: a portal, a CLI, or the codebase.

## Wisdom

When a question needs real-world judgement, attempt an answer, then point the user to a high-reputation community from `RESOURCES.md` (a forum, subreddit, class, or local group). Respect a preference not to join one.

## Preferences

When the user states how they want to be taught, record it in `NOTES.md` and apply it in later sessions.
